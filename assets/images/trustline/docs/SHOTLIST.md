# Trustline user guide: screenshot shot list

Drives step 2 (capture). Each row is one image referenced from `tools/trustline/docs.md`. The files do not exist yet: save each as `Trustline-<Area>-<slug>.png` in this folder, using the filename in the first column exactly.

## Setup

1. Seed isolated demo data: `python3 trustline/scripts/seed-demo-data.py <fake-home>`, then launch the Trustline binary with `HOME=<fake-home>` so `dirs::data_dir()` resolves into it. Every name is invented and every address is under `example.com`; never capture real data.
2. Window: the default 1100 x 720 minimum is too tight for tall panels. Use one size for every shot (suggested 1280 x 800, same as the existing Threadline set), the macOS build, and **Light** theme unless the row says otherwise.
3. Rows marked "throwaway" delete or change data. Run them in a second seeded copy, or re-seed afterwards (the seed script wipes and rewrites the folder).
4. Avoid real paths, user names and e-mail addresses in any visible field. Use the fake-home path and `example.com`.
5. Seeded dates are in 2026; "due" and "overdue" banners depend on the capture date and are fine as they appear.
6. Seed quirk: the demo levels are numbered 0 and 1, so the app will label them "Level 0" and "Level 1". The docs text does not quote a level number. Decide whether to re-seed with 1-based levels before capturing.
